# Mascotte Spy — inserisci qui le immagini

Salva le immagini della mascotte in questa cartella con **esattamente** questi nomi (PNG, fondo trasparente, almeno 1024 px sul lato lungo):

| File | Posa |
|---|---|
| `spy-frontale.png` | Frontale, neutra |
| `spy-saluto.png` | Saluta, archi luminosi |
| `spy-chiave.png` | Tiene la chiave |
| `spy-accesso-negato.png` | Braccia incrociate, archi rossi |
| `spy-accesso-consentito.png` | Salto felice |
| `spy-standby.png` | Occhi chiusi, archi grigi |
| `spy-icona.png` | Solo testa in un quadrato arrotondato |

Se hai un'unica immagine con tutte le pose (character sheet), ritaglia ogni posa in un file separato.
Le regole d'uso sono nel §8 di `BRAND.md`.
